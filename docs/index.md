# ThreatVision AI — Documentation

Welcome to the official documentation for **ThreatVision AI**, a production-grade, open-source AI-powered real-time threat detection computer vision framework.

---

## Key Features

- 🎥 **Multi-Camera & RTSP Support**: Live webcam, IP camera streams, RTSP, CCTV feeds, mobile cameras, video files, and single images.
- 🎯 **11 Specialized AI Detectors**: Person, Gun/Rifle/Knife, Fire, Smoke, Vehicles (Car, Truck, Bus, Motorcycle, Bicycle), Vehicle Collisions, Physical Fights/Violence, Falls/Lying Down, Restricted Zone Intrusion, Crowd Panic, Unattended Packages.
- 📐 **Multi-Object Tracking**: Persistent tracking IDs, entry/exit counters, spatial heatmaps, trajectory visualization, loitering dwell time.
- ⚡ **Calibrated Threat Scoring Engine**: Real-time Threat Score (0–100%) and Threat Level classification (SAFE, LOW, MEDIUM, HIGH, CRITICAL).
- 🚨 **Multi-Channel Alert Dispatcher**: Telegram, Discord, Slack, MS Teams, Webhooks, Email (SMTP), Desktop notifications, Audible alarms.
- 📁 **Automated Incident Recording**: High-resolution screenshots, JSON metadata, CSV logs, and automated ReportLab PDF reports.
- 🌐 **Cloud REST API & Web Dashboard**: Built-in FastAPI backend, OpenAPI docs, and modern responsive glassmorphism dark dashboard.
- 🔌 **Extensible Plugin Architecture**: Custom detector SDK with simple Python class inheritance.
