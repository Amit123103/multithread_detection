# ThreatVision AI Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

Safety and security are fundamental to ThreatVision AI.

If you discover a security vulnerability within ThreatVision AI, please **do not** open a public issue. Instead, send an email to `security@threatvision.ai`.

Please include:
- A description of the issue.
- Steps to reproduce or proof-of-concept code.
- Impact assessment.

We aim to respond within 24 hours and issue a patch release promptly.

## Safety & Ethics Statement
ThreatVision AI is designed exclusively as an operator assistance framework. Detections represent probability estimates and must be verified by trained human operators. ThreatVision AI must not be used for automated autonomous force application or unlawful surveillance.
